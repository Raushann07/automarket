\# AutoMarket



\## Жоба туралы

AutoMarket — автокөлік сату және сатып алуға арналған веб-платформа.



\## Жобаның мақсаты

PHP және MySQL технологияларын пайдаланып, автокөлік туралы хабарландыруларды жариялауға, қарауға және іздеуге мүмкіндік беретін веб-қосымша әзірлеу.



\## Қолданылатын технологиялар

\- PHP

\- MySQL

\- HTML

\- Git

\- GitHub

\- XAMPP



\## Негізгі беттер

\- `index.php` — жобаның басты беті.

\- Тіркелу және кіру беттері — келесі кезеңдерде әзірленеді.

\- Автокөлік туралы ақпарат беті — келесі кезеңде әзірленеді.



\## Негізгі мүмкіндіктер

\- Автокөліктер туралы хабарландыруларды қарау.

\- Автокөлік туралы хабарландыру қосу.

\- Маркасы және бағасы бойынша іздеу.

\- Пайдаланушыны тіркеу және жүйеге кіру.

\- Хабарландыруларды өңдеу және жою.



\## Дерекқордың жоспарланған құрылымы

1\. `users` — пайдаланушылар туралы ақпарат.

2\. `cars` — автокөліктер туралы ақпарат.

3\. `favorites` — таңдаулы автокөліктер.
