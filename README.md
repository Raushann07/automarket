# AutoMarket — Автокөлік сату және сатып алу платформасы

## 1. Жоба туралы

AutoMarket — автокөлік сатушылар мен сатып алушыларға арналған веб-қосымша. Жүйе пайдаланушыларға автокөлік туралы хабарландыруларды қарауға, қажетті көлікті іздеуге және өз автокөлігін сатуға жариялауға мүмкіндік береді. Жобаның мақсаты — автокөлік сату және сатып алу үдерісін жеңілдететін ыңғайлы әрі қауіпсіз веб-платформа әзірлеу.

## 2. Жобаның негізгі мүмкіндіктері

- **Тіркелу және авторизация:** пайдаланушылар аккаунт құрып, жүйеге кіре алады.
- **Хабарландыруларды басқару:** автокөлік туралы ақпаратты қосу, қарау, өңдеу және жою (CRUD).
- **Іздеу және сүзгілеу:** көліктерді маркасы, моделі, бағасы және шығарылған жылы бойынша іздеу.
- **Автокөлік туралы ақпарат:** көліктің бағасын, жүріп өткен қашықтығын, сипаттамасын және суреттерін көрсету.
- **Таңдаулылар:** қызықты автокөліктерді жеке тізімге сақтау.
- **Деректерді қорғау:** енгізілген ақпаратты тексеру және пайдаланушының құпиясөзін қауіпсіз сақтау.

## 3. Қолданылатын технологиялар

- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend:** PHP.
- **Database:** MySQL.
- **Дерекқорға қосылу:** PDO.
- **Жергілікті сервер:** XAMPP.
- **Нұсқаларды басқару:** Git және GitHub.

## 4. Дерекқор құрылымы

Жобада келесі негізгі кестелерді қолдану жоспарланған:

- **users** — пайдаланушылардың идентификаторы, аты, электрондық поштасы, құпиясөз хэші және рөлі.
- **cars** — автокөліктің маркасы, моделі, шығарылған жылы, бағасы, жүріп өткен қашықтығы және сипаттамасы.
- **favorites** — пайдаланушылар таңдаулыларға қосқан автокөліктер туралы мәліметтер.
- **car_images** — автокөліктерге тіркелген суреттердің файл жолдары.

## 5. Жобаның негізгі беттері

1. `index.php` — басты бет және автокөліктер тізімі.
2. `register.php` — жаңа пайдаланушыны тіркеу.
3. `login.php` — жүйеге кіру.
4. `car_detail.php` — автокөлік туралы толық ақпарат.
5. `add_car.php` — автокөлік туралы хабарландыру қосу.
6. `edit_car.php` — хабарландыруды өңдеу.
7. `favorites.php` — таңдаулы автокөліктер тізімі.
8. `profile.php` — пайдаланушының жеке кабинеті.

Ескерту: бұл беттер жобаны әзірлеу барысында кезең-кезеңімен қосылады. Қазіргі бастапқы нұсқада басты бет пен README файлы дайындалған.

## 6. ER-диаграмма

ER-диаграмма AutoMarket дерекқорындағы кестелерді, олардың негізгі өрістерін және өзара байланыстарын көрсетеді.

![AutoMarket ER Diagram](er-diagram.png)

### Кестелер арасындағы байланыстар

- **users → cars (1:N):** бір пайдаланушы бірнеше автокөлік туралы хабарландыру жариялай алады.
- **users → favorites (1:N):** бір пайдаланушы бірнеше автокөлікті таңдаулыларға қоса алады.
- **cars → favorites (1:N):** бір автокөлік бірнеше пайдаланушының таңдаулылар тізімінде болуы мүмкін.
- **cars → car_images (1:N):** бір автокөлікке бірнеше сурет тіркеуге болады.

**PK (Primary Key)** — кестедегі жазбаны бірегей анықтайтын негізгі кілт.

**FK (Foreign Key)** — кестелер арасындағы байланысты қамтамасыз ететін сыртқы кілт.

## 7. Қауіпсіздік

Жүйені әзірлеу кезінде құпиясөздерді хэштеу, PDO арқылы параметрленген SQL сұраныстарын қолдану, пайдаланушы енгізетін ақпаратты тексеру және рұқсатсыз өзгерістерден қорғау қарастырылады.

## 8. Жобаны іске қосу

1. XAMPP бағдарламасын ашып, Apache серверін іске қосу.
2. Жоба бумасын `C:\xampp\htdocs\automarket` мекенжайында сақтау.
3. Браузерде `http://localhost/automarket/` мекенжайын ашу.
4. Дерекқорды пайдаланатын функциялар іске асырылғаннан кейін MySQL қызметін қосып, қажетті кестелерді құру.

## 9. Жобаның мақсаты мен күтілетін нәтижесі

Жобаның нәтижесінде автокөліктер туралы хабарландыруларды басқаруға, қажетті көлікті іздеуге және таңдаулылар тізімін жүргізуге арналған веб-қосымша әзірлеу көзделеді. Жоба PHP, MySQL және Git технологияларын практикалық тұрғыда қолдануға мүмкіндік береді.
