\# AutoMarket — Автокөлік сату және сатып алу платформасы



\## Жоба туралы

AutoMarket — пайдаланушыларға автокөліктер туралы хабарландыруларды көруге, қажетті көлікті іздеуге және өз автокөлігін сатуға жариялауға арналған веб-қосымша. Жүйе автокөлік туралы ақпаратты ыңғайлы түрде ұсынуға және сатушы мен сатып алушы арасындағы байланысты жеңілдетуге бағытталған. Жоба PHP және MySQL технологиялары арқылы әзірленеді.



\## Негізгі мүмкіндіктері

\- Пайдаланушыларды тіркеу және жүйеге кіру.

\- Автокөлік туралы хабарландыруларды қосу, қарау, өңдеу және жою (CRUD).

\- Автокөліктерді маркасы, моделі және бағасы бойынша іздеу және сүзгілеу.

\- Автокөліктің шығарылған жылы, жүріп өткен қашықтығы және техникалық сипаттамалары туралы ақпаратты көрсету.

\- Қажетті автокөліктерді таңдаулылар тізіміне қосу.

\- Енгізілген мәліметтерді тексеру және пайдаланушы деректерінің қауіпсіздігін қамтамасыз ету.



\## Дерекқор құрылымы (Tables)

\- \*\*users\*\* — пайдаланушылардың тіркелу деректері мен аккаунт ақпараты.

\- \*\*cars\*\* — автокөліктердің маркасы, моделі, бағасы, шығарылған жылы және сипаттамасы.

\- \*\*favorites\*\* — пайдаланушылар таңдаулы ретінде сақтаған автокөліктер туралы мәліметтер.



\## Технологиялар

\- \*\*Frontend:\*\* HTML5, CSS3, JavaScript.

\- \*\*Backend:\*\* PHP.

\- \*\*Database:\*\* MySQL.

\- \*\*Database connection:\*\* PDO.

\- \*\*Development environment:\*\* XAMPP.

\- \*\*Version control:\*\* Git және GitHub.
